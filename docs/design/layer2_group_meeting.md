# 分区边界的平滑修正：组会讲稿

> 面向数学背景听众。尽量不用计算机视觉术语；重点是问题结构、数学形式和实验结论。
> 原始调研见 `docs/design/layer2_smoothing_survey.md`，实验实现见 `experiments/layer2/`。

---

## 1. 一句话说清楚问题

一张地质剖面图已经被涂成若干色块，每个色块代表一个速度/地层单元；色块与色块之间的分界线就是我们要处理的**边界**。

现在的局面是：

- 色块划分已经给定，来自前一步的分区结果；
- 我们不重新划分色块；
- 只修正分界线的几何形状，使它不要有像素锯齿，但也不能把真实的地质转折、断层、尖灭抹掉。

所以这不是“从图像里重新找边界”，而是：

> 给定一个平面分区，把它的边界网络修成一条条可用的、保持拓扑关系的曲线。

---

## 2. 必须先分开的两件事

这是整个工作的核心，也是之前走弯路的根源。

### 2.1 第一件事：这条边界该不该存在？

边界可能来自真实地层界面，也可能来自文字、遮挡、噪声、错误分区。

这一步只做离散判断：

- 保留（keep）；
- 待审核（review）；
- 删除（remove）。

当前原则是保守：**不自动删除**。不确定就保留原样，交给视觉审计。

### 2.2 第二件事：在它存在的前提下，线该画在哪里？

这一步只做几何：

- 让线更平滑；
- 让线贴近原来的分区边界；
- 不改变哪些区域相邻、不制造交叉、不吞掉薄层。

**这两件事不能混在一起。** 如果平滑算法可以顺手删边界，就永远说不清一条边界是“被平滑掉了”还是“本来就不该存在”。

## 3. 数学化

### 3.1 分区与边界

设平面区域为 Ω ⊂ ℝ²，分区编号为

    L: Ω → {0, 1, …, K}

两个相邻编号 i、j 的边界记为

    Γᵢⱼ = cl(∂{L = i} ∩ ∂{L = j})

其中 cl 表示闭包。在离散图像里，第一步不是拟合，而是取所有“左右/上下相邻、编号不同”的像素并集：

    B(L) = { x ∈ Ω : 存在 y ~ x，使 L(y) ≠ L(x) }

这里的 ~ 表示 4 邻域。更具体地，先按每一对相邻编号取 Γᵢⱼ，再对所有编号对取并集：

    B(L) = ⋃_{a<b} Γₐᵦ(L)

这一步是**唯一**的：给定 labels 和邻接规则，边界集合就确定了。它不做骨架、不做剪枝、不做平滑，也不判断该不该保留。

注意两个约定：

- 默认 `boundary_union(labels)` 把 transition 两侧的像素都标出来，得到对称的边界带；
- `boundary_union(labels, side="lower")` 只保留每一对 transition 中 label 较小的一侧，这是逐对象提取时使用的 canonical 单侧代表。两者都是确定的，但含义不同，不能混用。

对应代码入口：`api.boundary_union(labels)`；它返回一个布尔 mask，不返回曲线。

在离散图像里，这个并集是一组有厚度的像素带，不是一条数学曲线。下一步才是把它变成一条有序的**中心线**，作为拟合的初始折线 P。中心线只用于几何拟合，不参与“保留/删除”的决定。

### 3.2 边界网络

多条边界会在三叉点、断层交点、尖灭点相遇。把它们看成一个平面图：

- 顶点：三叉点、panel 边界端点、断层交点、尖灭点；
- 边：两个顶点之间的一段边界。

每条边单独拟合。**不跨顶点做全局拟合**，因为顶点是拓扑约束，不是可以随便移动的几何点。

这解释了一个实验现象：不做端点固定时，边界端点会漂移 2–3 像素，并产生多条边界相交；把端点固定后，端点漂移为 0，交叉也消失。

### 3.3 一条边界的拟合问题

给定一条边的初始折线 P(s)（按弧长参数化，s ∈ [0,1]），要找一条曲线

    γ: [0,1] → ℝ²

使它：

1. 贴近 P；
2. 不剧烈弯曲；
3. 不出现无意义的抖动；
4. 端点、拓扑和地质不连续点保持不动。

一个自然的能量是

    E(γ) = ∫₀¹ ‖γ(s) − P(s)‖² ds
         + λ ∫₀¹ κ(s)² ds
         + μ ∫₀¹ (κ′(s))² ds

三项分别控制三件事：

- 第一项：不要离原来的分区边界太远；
- 第二项：总弯曲不要太大，等价于“橡皮筋/弹性梁”的能量；
- 第三项：曲率不要忽大忽小，防止出现尖点、过冲和虚假拐弯。

其中曲率是

    κ(s) = |x′(s)y″(s) − y′(s)x″(s)|
           / (x′(s)² + y′(s)²)^(3/2)

如果只保留第二项，就得到经典的最小曲率曲线；它有一个已知问题：在稀疏约束之间可能产生过冲和虚假拐点。第三项或“张力”就是用来压住这个问题的。

### 3.4 为什么是三次样条

在只有插值/端点约束、没有不等式约束时，最小化

    ∫ (f″)²

的解是三次样条。直观地说：

- 三次多项式是“四阶导数恒为零”的最简单函数；
- 它对应一根受弯的细梁；
- 在所有穿过给定点的光滑曲线里，它的总弯曲能最小。

所以“三次样条”不是随便选的多项式，而是这个变分问题的自然解。二维参数曲线可以对 x(s)、y(s) 分别做同样的拟合。

实际计算用 B 样条基展开：

    γ(s) = Σ_{k=1}^{m} c_k B_k(s)

其中 B_k 是三次 B 样条基函数，c_k ∈ ℝ² 是控制系数。于是能量变成一个二次型：

    min_c ‖Bc − y‖² + λ‖D₂c‖² + μ‖D₃c‖²

其中 D₂、D₃ 是二阶、三阶差分矩阵。它们分别惩罚“弯曲”和“曲率变化”。

端点条件

    γ(0) = p₀,    γ(1) = p₁

是线性等式约束，可以直接消去首末控制系数；如果要约束端点切向，则是

    γ′(0) = t₀,   γ′(1) = t₁

同样是线性约束。

### 3.5 曲率、尖角和“折返”

一条 C¹ 曲线在每一点有有限曲率；但一条**有尖角**的曲线在角点没有有限曲率。若硬把尖角“磨圆”，会出现两种情况：

- 磨得很轻：曲率仍然极大，数值上像一个很尖的弯；
- 磨得很重：角被抹掉，几何事实被改变。

所以正确做法不是“把所有角都磨圆”，而是：

1. 检测方向反转/尖角；
2. 判断它是真实地质角点、尖灭、还是中心线提取产生的假折返；
3. 把它当作**分段点**：在角点把曲线切开，两侧分别拟合，共享端点，但允许切线不连续（C⁰ 连接）。

这就是“hairpin（折返）”处理。它保留角，而不是把角磨成一个小环。

### 3.6 硬约束与拓扑

仅有能量还不够。必须加硬约束：

- 端点固定；
- 曲线留在原始边界附近的容许带内：

      dist(γ(s), Γ) ≤ δ

- 不自交；
- 不同边界不交叉（共享顶点除外）；
- 区域邻接关系不变；
- 区域连通分量数、孔洞数不变；
- 断层两侧的错距不被抹平；
- 闭合体（透镜、盐体、河道）面积/宽度不塌缩。

前几条是几何约束，后几条是**离散拓扑不变量**。拓扑不是能量项能自动保证的东西，必须单独检查。

工程上的处理是：

1. 先解一个带线性约束的二次问题；
2. 再检查非线性约束（容许带、曲率、自交、互交、面积/宽度）；
3. 违反就把平滑强度减半，重新拟合；
4. 仍违反就退回原始精确边界，并标记 `fallback`。

这不是“全局拓扑优化”，而是一个保守的“求解—校验—回退”流程。全局拓扑约束通常是 NP-hard，局部校验 + 回退更可靠，也更符合“绝不误删”的要求。

## 4. 实验过程

所有实验使用同一批 11 个 panel、同一套 keep 边界、同一套度量。`ph01` 的分区本身缺层，单独报告，不参与调参。

### 实验 A：最朴素的“分段 + 约束样条”

做法：

- 每条边界单独拟合；
- 三次 B 样条，8 像素一个节点；
- 弯曲 + 曲率变化惩罚；
- 两端固定；
- 3 像素容许带；
- 违反约束就降低平滑强度，最后回退原边界。

结果（非 ph01、150 条可平滑边界）：

- 中位 p95 偏离 **0.80 像素**；
- 中位最大曲率下降 **84%**；
- 边界自交/互交 **0**；
- 闭合体最大面积变化 **0.43%**。

结论：这套“约束样条”已经是一个可靠的基线。它的主要问题不是拓扑，而是少数中部折返的曲率仍然很大。

### 实验 B：换平滑核

在完全相同的边界上比较：

- `splprep` 平滑样条；
- 最小二乘 B 样条；
- 二阶差分惩罚 P 样条；
- Savitzky–Golay；
- 五次局部回归。

结果：

- 最小二乘 B 样条最稳：平均 p95 偏离 **1.20 像素**，互交 **0**；
- `splprep` 稍微更平滑，但产生 4 条互交；
- 其他核有 7 条互交，或 8–9 像素的最大偏移。

结论：**平滑核不是主要矛盾，约束和校验才是。** 换一个更“高级”的平滑器，不会自动解决拓扑问题。

### 实验 C：端点、断层和拓扑

比较四种处理：

- 全局平滑，不管端点；
- 固定端点；
- 识别断层/拐点后分段；
- 再加拓扑校验和回退。

结果：

- 不固定端点：端点漂移 2.9 像素，8 条互交；
- 固定端点：漂移 0，互交 0；
- 合成断层上，显式断层处理把角点误差从 **2.42 像素降到 0**；
- 但在真实 panel 上，没有断层标注、只靠几何猜断层，会把拓扑违规从 1 条增加到 3 条。

结论：**端点固定是必须的；断层处理必须有明确证据，不能靠曲率猜。**

### 实验 D：闭合体

- 大的闭合体（透镜、盐体）面积几乎不变，原始面积变化最大 **0.04%**；
- 小闭合体很危险：ph01 的环损失 3.8%，4 像素的环直接塌缩；
- 面积恢复可以把最终面积误差压到 **0.002%**，但可能把宽度撑大，所以必须再检查最终宽度；
- 图像方向先验对结果几乎没有影响。

结论：闭合体只需要对“小体/退化体”做面积和宽度保护；不需要为它引入复杂模型。

### 实验 E：端点切向

给端点加“切向对齐”的软约束：

- 端点区最大曲率下降 **8.5%**；
- 代价是 p95 偏离从 0.801 增到 0.806 像素；
- 但 A 报的两个最坏点其实不在端点：一个距端点 **312 像素**，一个距端点 **128.6 像素**。

结论：端点切向是一个小改进，不是主问题的解。真正的问题是路径中部的折返。

### 实验 F：折返/尖角

检测方向反转（小窗口转角、密集曲率），得到 28 个候选点，比较：

- 原样一条曲线拟合；
- 在折返点切开，两段分别拟合；
- 在折返点加强制角点；
- 用局部曲率上限强行压。

结果（非 ph01、150 条可平滑边界）：

| 处理 | 中位折返处最大曲率 | 最大折返处曲率 | 中位 p95 偏离 | 拓扑违规 |
|---|---:|---:|---:|---:|
| 不切 | 0.982 | 12.386 | 0.801 | 0 |
| **切开** | **0.205** | **0.721** | **0.801** | **0** |
| 硬角点 | 0.191 | 0.826 | 0.801 | 0 |
| 曲率上限 | 0.876 | 1.929 | 0.801 | 0 |

具体例子：

- `schematic_panel2` p37：密集曲率最大值 **12.39 → 0.29**；
- `paper23_fig7a` p13：**1.66 → 0.41**；
- `newimage_p4` p4：**2.71 → 0.28**。

结论：

- **“在折返点切开”是最安全的默认做法**；
- 它保留原来的转角，不假设角点两侧的切向；
- 代价是留下一个 C⁰ 连接：在连接点曲率在数学上是奇异的，不能声称“处处光滑”；
- 局部曲率上限不安全：没有转角保护时，它可以把 141° 的折返压成 24° 还报告“成功”；
- 但“检测到折返”不等于“必须切”：`paper23_fault_guided` 里还有 3 处宽缓 U 形弯，切开后测得转角反而变大。检测器只能提出候选，最终要回到分区图判断它是真角点、尖灭还是伪影。

### 实验 G：路径清洗的负结果

第一版把边界中心线拆成了 376 条路径，其中 186 条很短。清洗后：

- 路径数 376 → **242**；
- 短路径 186 → **58**；
- 但真正可平滑的非 ph01 路径仍然是 **150 条**；
- 所有平滑指标完全不变。

结论：短路径确实是指中心线提取的伪影，但清洗它只改善统计和回退，不改善平滑质量。

## 5. 最终得到的条件

可以把最终方案压缩成下面几条。它们不是“调参经验”，而是由问题结构决定的。

### 条件 1：边界来源

边界必须是分区结果的精确闭边界：

    Γᵢⱼ = cl(∂{L = i} ∩ ∂{L = j})

不从颜色重新分割，不用平滑结果反过来改变分区。

### 条件 2：先决定保留，再谈几何

保留/删除是离散判断；平滑只作用于已经保留的边界。平滑失败只能回退原边界，不能删除。

### 条件 3：建立边界网络

在以下位置切开：

- 三叉点/多叉点；
- panel 边界端点；
- 断层/不整合；
- 方向反转的尖角/折返；
- 尖灭点。

每条边单独拟合，顶点固定。不跨顶点做全局样条。

### 条件 4：约束三次样条

对每条边解

    min_γ ∫ ‖γ − P‖² + λ ∫ κ² + μ ∫ (κ′)²

并满足：

- 端点固定；
- 留在 δ 容许带内；
- 曲率有上限；
- 不自交、不互交；
- 断层错距、区域邻接、连通分量/孔洞不变；
- 闭合体面积/宽度不塌缩。

离散形式就是带约束的二次规划：

    min_c ‖Bc − y‖² + λ‖D₂c‖² + μ‖D₃c‖²

线性约束直接消元，非线性约束用“求解—校验—回退”。

### 条件 5：折返当角点，不当噪声

方向反转超过阈值时，先判断它是真实角点、尖灭还是中心线伪影；确认后切开，保留 C⁰ 角，不硬磨圆。

### 条件 6：断层必须有证据

没有明确断层标注/掩膜时，不自动做断层感知平滑；标为待审核，保留原样。几何上的高曲率不能单独证明是断层。

### 条件 7：闭合体单独保护

闭合曲线用周期样条；面积和宽度都要检查。小体/退化体直接回退原边界。

### 条件 8：审计 baseline 是分区重着色图

视觉审计看“分区重着色后的 mask”，不是原照片，也不是降噪照片。边界要画粗、加深色描边，否则人眼无法判断。

## 6. 数学本质

如果只用几句话概括：

1. **这是一个带约束的变分问题。** 我们不是“滤波”，而是在所有满足拓扑/地质条件的曲线里，找一条最接近原边界、弯曲能量最小的曲线。

2. **三次样条是弯曲能量最小的解。** 端点条件是边界条件；曲率变化惩罚是更高阶的正则化；容许带和拓扑是约束集。

3. **拓扑是离散不变量，不是能量项。** 邻接关系、连通分量、孔洞、断层错距必须单独检查；靠平滑能量无法保证。

4. **尖角是奇异点。** 有尖角的曲线没有有限曲率；正确做法是把尖角当分段边界，而不是把它磨成一个小环。C⁰ 连接是保留几何事实的代价。

5. **实验本质上是在做约束消融。** A/B/C/D/E/F 不是六个模型，而是在回答：哪些约束是必要的？答案依次是：端点固定、容许带、拓扑校验、折返分段、闭合体保护；平滑核和端点切向都不是主要矛盾。

## 7. PPT 页面建议

1. **一张图**：彩色分区图，圈出几条边界；一句话说明“色块已给定，只修线”。
2. **两件事分开**：保留判断 vs 几何修正；强调不能互相污染。
3. **数学对象**：Ω、L、Γᵢⱼ、边界网络（顶点/边）。
4. **能量**：贴近项 + 弯曲项 + 曲率变化项；写出 κ 公式。
5. **为什么三次样条**：弯曲能量最小解；B 样条离散；线性系统。
6. **硬约束**：端点、容许带、不交叉、邻接/孔洞、断层错距、闭合体面积。
7. **尖角**：曲率在角点无界；磨圆 vs 切开；C⁰ 连接。
8. **实验表**：A–F 的关键数字（p95 偏离、曲率下降、拓扑违规）。
9. **最终条件**：8 条 checklist。
10. **结论**：约束比平滑器重要；先拓扑后几何；不确定就回退/待审。

## 8. 可能被问到的问题

**Q：为什么不直接用一个更强的平滑器？**

A：实验 B 表明，换平滑核对互交和最大偏移的改善有限；真正起作用的是端点固定、容许带和拓扑校验。

**Q：为什么不用全局样条一次拟合所有边界？**

A：全局样条会跨三叉点/断层，导致顶点漂移和边界互交。边界网络必须按顶点分段。

**Q：为什么不把所有角都磨圆？**

A：角点曲率无界；磨圆要么留下极大曲率，要么改变几何事实。正确做法是保留角点，分段拟合。

**Q：为什么不用深度学习方法？**

A：当前输入已经是分区 labels，边界位置由分区决定；学习模型会重新解释边界，无法保证拓扑和“不误删”。它最多提供方向/置信度先验，不能替代约束。

**Q：怎么证明没有误删？**

A：保留集合在几何修正前固定；几何阶段失败只能回退原边界，不能删除。拓扑检查再保证区域/孔洞/邻接不变。
