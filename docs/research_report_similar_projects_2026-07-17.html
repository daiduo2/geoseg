geoseg v2 同类项目调研报告

面向地球物理 / 大气测量学 / 地质学三大领域，系统调研与 geoseg v2（PDF figure → 概念物理模型 → SPECFEM 工件）管线可对标的工具与研究项目。
结论：调研范围内无完整对标，geoseg v2 的 M0.5→M4 全闭环具有显著差异化。

📅 调研日期 2026-07-17 🔬 检索关键词 24 组 📚 命中工具 / 论文 30+ 🎯 4 大领域（地球物理 + 大气 + 地质 + 通用 chart）

1TL;DR · 核心结论

把调研压缩成 4 张卡片，每张只回答一个决策问题。

唯一性

无完整对标项目

PDF → 多 figure → panel 分割 → 多引擎融合 → SPECFEM 工件的全闭环管线，在地球物理 / 大气 / 地质领域均未发现直接对标。最接近的工作都只覆盖其中一段。

最相关

上游/邻域间接相关

WebPlotDigitizer / DePlot / UniChart 覆盖"chart→data"，FaultSeg3D / striplog 覆盖"邻域（SEG-Y 体数据 / 钻孔 log 数字化）"，但都不解决 geoseg 的"论文 figure 反向 → 概念模型"问题。

空白

大气 / 地质几乎空白

大气 Skew-T 反向数字化、地质剖面/地层柱状图反向数值提取 — 调研范围内没有看到对标项目，存在先发迁移窗口。

短板

geoseg 自身短板

没有公开 benchmark，对外对标困难；Figure2Data 2025-09 等评测方法论可借鉴，建议自建 geoseg-bench。

差异化一句话：

geoseg v2 = PDF 提取 + colorbar → 物理值映射 + 多分割引擎族（agent 自主选/评/融） + 视觉审计 + SPECFEM 导出。任何单一工具都只占其中一段。

3geoseg v2 项目定位

回顾项目自身的设计边界，避免拿不同 scope 的工具做不公平对比。

核心目标

PDF figure → 概念物理模型 → SPECFEM 工件

导师导入文献 PDF → Agent 自动分析 → 多引擎分割 → HITL 编辑 → 一键导出 SPECFEM2D/3D 模型。

PDF → figure panel 分割 colorbar 反演 SPECFEM 导出
Scope 红线

只做概念模型提取

不做反射振幅图正演、不做波形反演、不做全波形反演参数调优。figure_classifier 宁可误拒，不可误放 observational_data。

架构骨架

M0.5 → M1b → M1.5 → M3 → M3.5 → M4

六阶段 pipeline；MinerU 主提取 + PyMuPDF fallback；多分割引擎族（kmeans / SLIC+graphcut / edge_guided / regional_fusion / v4 / horizon refinement）；sandbox-segment agent 自主选/评/融。

交互范式

Agent-Native CLI HITL + napari

所有语义判断走 Claude Code agent 直接读图，不写 VLM client 调 CLI；Tauri/FastAPI 前端 v0.7 后已废弃；批量处理 ≤5 并发 agent。

6三大领域详细调研

每个领域独立成节：找到什么 / 没找到什么 / 对 geoseg 的启示。

A · 地球物理 / 地震（最相关）

项目 / 论文领域覆盖段与 geoseg 差异
FaultSeg3D Wu et al., 2019地球物理3D SEG-Y 体积断层分割输入是体数据，不是论文 figure
FaultNet / SE-Net IEEE GRSL 2018地球物理3D 断层解释同上，SEG-Y 立方体
Thebe / Parihaka / Kerry 公开数据集地球物理断层 benchmark数据集/benchmark，不是工具
SegyIO / PyLops地球物理SEG-Y I/O + 线性算子底层库，无 figure 处理
Full Waveform Inversion Springer 2017地球物理地震反演算法本身不接受图像输入
Omega2 / Seismic Unix / Madagascar地球物理地震处理软件完全不同 pipeline 入口（SEG-Y 原始数据）
Geophysical model w/ GAN Geosci. Lett. 2022地球物理用 GAN 生成速度模型生成方向，非反向提取
启示：

地球物理领域对 3D SEG-Y 体数据有完整 DL 工具链，但对 "论文 figure 反向 → 数值模型" 这条路径没有对标。geoseg 的 M0.5→M4 链路是独有。如果未来 scope 扩到 SEG-Y 体数据，会与 FaultSeg3D 体系正面撞车。

B · 大气测量学（覆盖最弱）

项目 / 数据集领域定位与 geoseg 差异
kocatepedogu/sounding-viewer大气Skew-T + hodograph viewer/editor只能画新的，不从论文 figure 反向数字化
SEVIR / HKO-7 / NEXRAD / KNMI大气雷达回波数据集原始体数据，非 figure
EarthFormer / Rainformer / ConvLSTM大气雷达外推/nowcasting预测，不是反演/数字化
ERA5 / NCEP / JRA-55 / MERRA-2大气再分析数据已是数值网格，无需反向
WebPlotDigitizer 等通用工具通用Skew-T 廓线点采样只能采曲线，不映射色块
启示（机会窗口）：

大气领域 完全没有 figure 反向数字化项目。Skew-T 图基本都是直接调 sounding 包生成，几乎没有"从论文图反向提取 sounding 廓线"的需求/工具。geoseg 概念迁移到大气（"色块图→大气参数 2D 场"）有先发优势。

C · 地质学（部分覆盖）

项目 / 工具领域覆盖段与 geoseg 差异
striplog agilescientific地质钻孔/露头 lithology log Python 库从已有数据建 log，不从图像反演
GeoScaler地质地质图尺度变换已是 vector 数据
Geovariances / GeoScene地质商业地质建模不接受 paper figure
GeoEast地质国产地震解释系统SEG-Y / 井数据，非 figure
CT 扫描 digital rock Arabian J Geosci 2023地质CT 切片 segmentation输入是 CT 切片
地质图 vectorization AI地质Raster2Vector + DL止步 GIS vector 层，不做物理属性分配
启示：

地质领域对 钻孔 log 数字化 有 striplog 这种结构化工具，但对 地质剖面图 / 地层柱状图 / 构造示意图反向提取数值 的项目没有对标。最接近的是地质图 vectorization（用 Raster2Vector + DL），但止步于 GIS vector 层，不做物理属性分配 / 导出到物理模型。

10SWOT · geoseg v2 战略四象限

基于本次调研的结构化结论，落到可执行的强弱机危。

💪 S · 优势（Strengths）

  • 全闭环：M0.5→M4 七阶段无任何对标
  • Colorbar → 物理值映射：竞品全无
  • 多引擎族 + agent 自主选/评/融：6 引擎 registry
  • Agent-Native 范式：CLI HITL + napari，无同类
  • Scope 红线清晰：不与 Omega2 / Madagascar 抢 SEG-Y 市场

⚠ W · 劣势（Weaknesses）

  • 无公开 benchmark：对标 / 宣传困难
  • Pipeline 复杂度高：7 stage + 6 engine 维护成本
  • 依赖 MinerU API：上游故障会传导
  • figure_classifier 假阴性可接受：但在批处理时可能过滤掉有效 figure
  • Napari 是阻塞 GUI：批处理并发受限于人工反馈

🚀 O · 机会（Opportunities）

  • 大气 Skew-T 反向数字化空白：可迁移 geoseg 概念
  • 地质剖面 / 地层柱状图反向提取空白：同上
  • Figure2Data 2025-09 评测方法论：可自建 geoseg-bench
  • LLM/VLM 持续进步：figure 分类质量上限持续提升
  • SPECFEM 用户群稳定：明确的买家画像

⚡ T · 威胁（Threats）

  • Datalab lift 类通用 PDF 提取：会压缩上游空间（但不做物理反演）
  • FaultSeg3D 等 3D SEG-Y 工具链成熟：若未来 scope 扩到体数据会撞车
  • Chart-to-data MLLM 迭代快：Figure2Data 等评测推动通用模型逼近专业能力
  • Agent 工具链不稳定：MCP / Claude Code 接口演进风险
  • 同领域内其他实验室自研管线：单点项目未开源难以追踪

11机会矩阵 · 拓展方向优先级

横轴=准备度（geoseg 现有能力可迁移程度），纵轴=吸引力（目标领域规模与可付费意愿）。

⭐ 优先

大气 Skew-T 反向

高吸引 + 高准备度（pipeline 可直接复用）。建议先做最小验证 fixture。

⭐ 优先

地质剖面图反向

高吸引 + 中准备度（需要重新训练 lithology 分类器）。

观察

通用 chart → data

吸引中等但 Figure2Data 等已布局；不建议正面竞争，做差异化（物理反演）。

避免

SEG-Y 体数据

FaultSeg3D 等成熟；扩 scope 会撞车。

12结论 & 下一步

核心结论：

geoseg v2 的 PDF figure → 多引擎分割 → colorbar → 物理值 → SPECFEM 工件 全闭环管线，在地球物理 / 大气测量学 / 地质学三大领域 + 通用 chart 工具范畴内均无完整对标。最相关的工作（WebPlotDigitizer / DePlot / FaultSeg3D / striplog）都只覆盖其中一段。

1. 立即可做

  • 用本报告作为对外介绍/PR 的差异化叙事素材
  • 把"无对标 + 全闭环"卖点写进 README 顶部
  • 写一份对外 blog / 论文草稿

2. 短期投入

  • 参考 Figure2Data 2025-09 自建 geoseg-bench
  • 补充 Figure2Data 等 SOTA 对比 baseline
  • 把本报告 SVG / 仪表盘作为 docs/ 资产

3. 中期方向

  • 大气：先做 Skew-T 反向数字化的最小验证 fixture
  • 地质：评估 striplog 集成路径，做剖面图反向提取 PoC
  • 关注 Datalab lift 类通用 PDF 工具对上游的影响

4. 不做（避免 scope creep）

  • 不做 3D SEG-Y 体数据（FaultSeg3D 已成熟）
  • 不做反射振幅正演 / FWI（违反 scope 红线）
  • 不与 Omega2 / Madagascar 抢通用地震处理市场
