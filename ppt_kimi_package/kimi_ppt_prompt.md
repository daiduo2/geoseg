## 第 4 页：Agent 自动化机制

Agent：从“看图”到“自动执行”的任务调度器

## 第 5 页：图像识别技术原理

标题：

从像素颜色到地质分区

核心文案：

1. 图像预处理：裁剪有效面板，去除文字、坐标轴和噪声影响。
2. 特征表达：利用 RGB/LAB 颜色空间、颜色条信息和边缘特征。
3. 区域分割：结合 K-Means、SLIC 超像素、区域融合和边界引导。
4. 模型转化：将 label map 转换为分区边界、多边形和材料区域。

版式建议：

做成 4 个横向步骤卡片：

Original Image → Preprocessing → Segmentation → Boundary Extraction

每个卡片配一个抽象小图标或从案例图裁剪的小图。

讲述重点：

算法不是直接“猜测地质解释”，而是先把图像转化为可计算的 label map，再从 label map 中提取界面和区域。
