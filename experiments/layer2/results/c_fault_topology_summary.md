# Layer 2 experiment C: fault/junction-aware smoothing and topology fallback

Run from the repository root:

```bash
uv run python -m experiments.layer2.c_fault_topology.run_experiment
```

The curated keep set is fixed by `load_panels()` + `keep_paths()`; nothing is re-segmented and no image diffusion is used.  All smoothing is per `BoundaryPath` (or per explicit fault/junction split), with a sparse Whittaker second-difference penalty.  The same lambda is used for every panel and variant.

## Fixed parameter selection (synthetic only)

Selected lambda = **400** from the global grid below, chosen as the largest value with synthetic mean p95 displacement <= 1.0 px, global max <= 2.0 px and mean p95-curvature ratio <= 0.35.  Selection took 7.05 s.  The same lambda is used on every curated panel.

| lambda | mean p95 disp | max disp | smooth/exact p95 curvature |
|---|---|---|---|
| 50 | 0.531 | 1.056 | 0.059 |
| 100 | 0.540 | 1.228 | 0.050 |
| 200 | 0.549 | 1.449 | 0.046 |
| 400 | 0.558 | 1.756 | 0.045 |
| 800 | 0.574 | 2.040 | 0.047 |
| 1600 | 0.600 | 2.505 | 0.045 |

## Variants

- `global`: per-path Whittaker smoothing, no endpoint or fault handling.
- `junction_pinned`: same smoother, both endpoints of every open path pinned.
- `fault_aware`: pin open endpoints; on synthetic cases use the explicit fault mask to split the path at fault-adjacent corners, pin those anchors and freeze a 2-px stencil on each side.  On curated panels no fault label exists: only junction/kink geometry is used, all such evidence is `review`, and ambiguous gaps are returned exact.
- `fault_aware_fallback`: fault-aware plus the global validator (self/cross intersections, new minimum-separation collapses, endpoint drift, displacement corridor, closed-area change, and synthetic fault-offset/corner checks), with iterative lambda halving and exact-geometry fallback.

## Failure cases and observations

- The final fault-aware-fallback geometry had no remaining topology violations; fallback either was unnecessary or repaired every flagged path.
- Fallback-specific failure cases:
  - `newimage_p3`: fault-aware base had 1 self-intersection; 8 lambda-halving rounds reduced the offending path (no exact fallback) and cleared the violation.
  - `ph01_page8_panel3` (under-segmented, reported separately): fault-aware base had 1 closed-area violation; 6 reduction rounds cleared it without exact fallback.
  - `paper23_fault_guided`: fault-aware base had 1 self-intersection at a junction-split path; 10 rounds reached the lambda floor and returned that path exact (1 fallback-exact path).
- On curated panels `global` has max endpoint drift 2.93 px and 8 cross-intersections; `junction_pinned` and `fault_aware` have 0.00 px drift and 0 cross-intersections. This is the junction-pinning effect, not a fault claim.
- 4 tiny closed skeleton loops (<16 points) were kept exact for every variant; periodic smoothing of these blobs silently changes area.
- 62 curated path/variant rows were returned exact as `review_exact_ambiguous_gap`; their offset evidence is too weak to justify a split.
- Fault-aware reduced the probe offset error relative to global for: syn_normal_fault/normal_throw (0.41 vs 0.83).
- Fault-aware *increased* the probe offset error for: syn_three_layer_fault/thin_bottom (0.56 vs 0.27).  These are short domains bounded by the fault; the corner itself is pinned but the segment between the fault and the probe is still smoothed at the global lambda. The fallback variant reduces lambda on exactly these paths.
- Synthetic max fault-corner error: global 2.42 px, junction-pinned 2.42 px, fault-aware 0.00 px, fault-aware-fallback 0.00 px.  The pinch-out has no fault and no violations in any variant.

Visual checks: see `contact.png` and `panels/<panel_id>_grid.png`.  The thin white line is the exact keep geometry; the thick green line is the variant output.  On the synthetic fault cases the red line is the explicit fault trace.  The curated panels have no fault trace on purpose.
