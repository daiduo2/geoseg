# 验收标准与视觉审计协议

## 1. 验收原则

- **视觉审计为主，量化指标为辅**。地质示意图的修复质量最终由人眼判断，PSNR/SSIM 仅作参考。
- **宁可保留微弱残留，不可模糊真实边界**。误伤地质结构线的代价比残留文字更高。
- **Per-panel 验收**。Panel 1/2（平坦渐变）与 Panel 3（复杂纹理）可能采用不同最优方案。

---

## 2. 视觉审计维度

对每一张实验输出图，从以下 5 个维度评分（1-5 分，5 为最佳）。

### 2.1 残留清除度（Residual Removal）

| 分值 | 标准 |
|------|------|
| 5 | 所有文字残留完全不可见，原文字区域与背景融为一体 |
| 4 | 极近距离（<20cm 屏幕距离）仔细辨认才能发现微弱痕迹 |
| 3 | 正常距离可看到淡淡痕迹，但不影响后续分割 |
| 2 | 残留明显，文字轮廓可辨识 |
| 1 | 残留严重，几乎等于未修复 |

**审计方法**：
1. 将实验输出与原图并排显示
2. 用鼠标在原图文字位置做 mental overlay，检查对应位置是否仍有痕迹
3. 重点检查区域：
   - Panel 1：顶部 "Continental crust"、中部 "Mantle lithosphere"、底部 "Mantle"
   - Panel 2：右侧 "removed mantle lithosphere"、顶部 "uplift"
   - Panel 3：左下角 "Fragments of removed mantle lithosphere"、中部 "weak zone"

### 2.2 边界保持度（Edge Preservation）

| 分值 | 标准 |
|------|------|
| 5 | 所有地质层位边界（灰/蓝、蓝/橙、橙/黄交界）完全锐利，无模糊 |
| 4 | 边界极轻微软化，需放大 2x 才能察觉 |
| 3 | 边界轻度模糊，但不影响分割引擎识别 |
| 2 | 边界明显模糊，可能出现混色带 |
| 1 | 边界完全消失或严重错位 |

**审计方法**：
1. 放大到 2x 观察层位交界线
2. 对比原图和实验输出，检查边界是否保持原有清晰度
3. 特别关注 Panel 2 顶部复杂褶皱结构和 Panel 3 绿色碎屑与橙色背景交界

### 2.3 颜色一致性（Color Consistency）

| 分值 | 标准 |
|------|------|
| 5 | 修复区域颜色与周围背景完全自然过渡，无可见色差 |
| 4 | 极轻微色差，需仔细对比才能发现 |
| 3 | 修复区域有轻微色差，但视觉上可接受 |
| 2 | 明显色差或斑块状色块，类似"补丁" |
| 1 | 严重色差或引入新颜色 |

**审计方法**：
1. 在文字原位置画假想圈，观察圈内与圈外颜色是否连续
2. 重点检查大面积文字区域（如 Panel 2 的 "removed mantle lithosphere" 纵向长文字）

### 2.4 伪影引入（Artifact Introduction）

| 分值 | 标准 |
|------|------|
| 5 | 无任何新伪影 |
| 4 | 极微小斑点或条纹，不干扰主结构 |
| 3 | 少量伪影，但不影响分割 |
| 2 | 明显伪影（条纹、棋盘格、过度平滑区域） |
| 1 | 严重伪影，破坏图像完整性 |

**常见伪影类型**：
- Telea/NS 大 radius：过度平滑产生的"糊状"区域
- Median blur 大 ksize：边界处产生阶梯状色带
- LaMa：可能 hallucinate 虚假地质特征
- Biharmonic：大区域可能有颜色"渗出"

### 2.5 结构完整性（Structural Integrity）

| 分值 | 标准 |
|------|------|
| 5 | 所有地质结构线（断层线、层位线、箭头、点划线）完整保留 |
| 4 | 极轻微断线或虚化，不影响语义理解 |
| 3 | 结构线轻度受损，但仍可辨识 |
| 2 | 结构线明显断裂或消失 |
| 1 | 关键结构被破坏 |

**重点保护结构**：
- 黑色断层线（Panel 1/2 顶部）
- 红色岩浆通道线（Panel 1/2 中部）
- 黑色箭头（Panel 2 右侧）
- 点划线边界（Panel 2 左右两侧）
- 蓝色碎屑块轮廓（Panel 3）

## 3. 审计流程

### 3.1 审计工具

使用 `napari` 或 `PIL.Image.show()` 并排对比。推荐排列方式：

```
+--------+--------+--------+
| 原图   | single | final  |  (上排：参考)
+--------+--------+--------+
| 实验A1 | 实验A2 | 实验A3 |  (下排：待审)
+--------+--------+--------+
```

### 3.2 审计顺序

1. **初筛**：快速浏览所有实验产出，排除明显失败结果（如严重模糊、大面积伪影）
2. **分组细审**：按实验组分别对比，每组内按参数从保守到激进排列
3. **交叉对比**：将各组最优结果并排，做最终排名
4. **双人复核**：至少两人在独立时间窗口完成评分，差异 >1 分的结果需讨论确认

### 3.3 评分表模板

```markdown
| 实验 ID | Panel | 残留清除 | 边界保持 | 颜色一致 | 伪影 | 结构完整 | 总分 | 备注 |
|---------|-------|----------|----------|----------|------|----------|------|------|
| A1-r3   | P1    | 4        | 5        | 4        | 5    | 5        | 23   |      |
| ...     |       |          |          |          |      |          |      |      |
```

总分 = 5 维度之和（满分 25）。

## 4. 通过标准

### 4.1 单项通过线

- **残留清除度 ≥ 3**：至少"不影响后续分割"
- **边界保持度 ≥ 4**：层位边界不能模糊
- **结构完整性 ≥ 4**：地质结构线必须保住

**任一单项低于通过线，该实验结果直接淘汰。**

### 4.2 最优方案选择

在所有通过单项通过线的结果中：

1. **第一优先级**：残留清除度最高者
2. **第二优先级**：边界保持度最高者
3. **第三优先级**：运行时间最短者（传统 CV < 1s/图 为优）

### 4.3 验收产出物

| 产出物 | 要求 |
|--------|------|
| 评分表 | 所有实验结果的 5 维度评分 |
| 最优参数表 | 每 panel 的最优方案 + 参数 |
| 失败案例分析 | 淘汰结果的失败原因（附带截图） |
| 集成建议 | 推荐接入 geoseg 管线的方案及代码接口 |

## 5. 量化指标（辅助参考）

### 5.1 自动计算指标

对每个实验结果计算：

```python
from skimage.metrics import peak_signal_noise_ratio, structural_similarity

def compute_metrics(original, result, mask=None):
    psnr = peak_signal_noise_ratio(original, result)
    ssim = structural_similarity(original, result, channel_axis=-1)
    if mask is not None:
        masked_psnr = peak_signal_noise_ratio(original[mask], result[mask])
    return dict(psnr=psnr, ssim=ssim)
```

### 5.2 指标使用规则

- **不直接用 PSNR/SSIM 排序**：这些指标偏好与原图相似，但文字移除本身就是"偏离原图"的操作
- **用途 1**：检测异常。若某结果 PSNR 显著低于同组其他结果，提示可能有严重伪影
- **用途 2**：修复区域局部对比。在 mask 区域内计算 PSNR，评估修复质量

## 6. 时间预算

| 阶段 | 预计时间 |
|------|----------|
| 环境准备 + 实验运行 | 4-6h（可后台运行） |
| 初筛 | 30min |
| 分组细审 | 1.5-2h |
| 交叉对比 + 双人复核 | 1h |
| 结论汇总 | 1h |
| **总计** | **8-10h** |
